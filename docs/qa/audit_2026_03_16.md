# Relatório de Auditoria de QA - 16/03/2026

**Estado:** Crítico (Regressões Detetadas)
**Auditor:** Advocatus IA QA Team

## 1. Resumo Executivo
Após uma análise minuciosa da estrutura de rotas e integridade do sistema, foram identificadas falhas que impedem a navegação fluida e o funcionamento de componentes core. O sistema apresenta links que levam a páginas 404 e funcionalidades que, embora implementadas, estão inacessíveis ao utilizador final.

## 2. Falhas Identificadas

### 2.1. Navegação e UI (Frontend)
- **Erro 404 - Rota /tasks**: O item "Tarefas" na Sidebar aponta para um diretório que não existe no projeto Next.js.
- **Funcionalidade Órfã - Inteligência Jurídica**: A rota `/intelligence` está funcional no backend e frontend, mas foi omitida da Sidebar, tornando-a "invisível".
- **Confusão de Rotas**: O ponto de entrada do dashboard (`/dashboard`) está a competir com a landing page em algumas configurações de redirecionamento.

### 2.2. Infraestrutura e Backend
- **Conflito Prisma v7**: O ambiente de execução está a utilizar o Prisma CLI v7.5.0, que introduziu alterações "breaking" na forma como as URLs de conexão são lidas (Erro P1012). O projeto ainda está configurado para o padrão v6.
- **Estabilidade do Servidor**: Verificou-se que a API pode falhar ao iniciar se as migrações não forem validadas com o novo padrão do Prisma.

## 3. Plano de Ação Imediato
1. **Correção da Sidebar**:
   - Remover/Corrigir o link `/tasks`.
   - Inserir o link para `/intelligence`.
2. **Estabilização do Prisma**:
   - Migrar a configuração do `datasource` para o novo padrão ou forçar a versão compatível.
3. **Varredura Playwright**:
   - Executar testes automatizados de "click-through" em todos os botões visíveis para garantir que nenhuma outra página "nem abre".

## 4. Conclusão
O sistema necessita de uma intervenção rápida nestes pontos de fricção para restaurar a confiança do utilizador. As correções propostas são de baixo risco e alto impacto positivo.
